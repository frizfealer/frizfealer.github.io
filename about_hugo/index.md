# ChatGPT Conversation Bookmarks

**Organize and navigate your ChatGPT conversations with ease**

A Chrome extension that adds powerful bookmarking and organization features to ChatGPT, making it easy to save, find, and reference important conversation moments.

---

## ✨ Features

### 📚 Bookmark Conversation Turns
Save any conversation turn with a custom name and quickly jump back to it later. Perfect for:
- Saving important answers for future reference
- Marking code snippets or examples
- Organizing research findings
- Tracking multi-session conversations

### 🎯 Floating Quick Access Widget
Hover over the floating bookmark button to instantly see all bookmarks in the current conversation:
- Real-time search and filtering
- One-click navigation
- Chronological ordering
- Delete unwanted bookmarks

### 🔗 Smart Citation Links
Automatically creates bidirectional links between questions and answers:
- Click cited text to jump to the original question
- Hover to preview the Q&A without scrolling
- Perfect for following long, complex conversations

### 📥 Export Conversations
Download entire conversations as clean Markdown files:
- Preserves formatting (code blocks, lists, tables)
- Removes extension UI elements
- Role labels (👤 User / 🤖 Assistant)
- Ready for documentation or archival

## 🔧 Troubleshooting

**Can't see the bookmark icons?**

If bookmark buttons don't appear next to your ChatGPT messages:
1. **Refresh the page** (press `F5` or click the refresh button)
2. Wait a few seconds for the page to fully load
3. Make sure you're on a ChatGPT conversation page (not the homepage)

The extension automatically detects new messages, but a refresh helps if something goes wrong during page load.

**Still having issues?**
- Try disabling and re-enabling the extension in Chrome's extension manager
- Check that the extension is enabled for `chatgpt.com` domains
- Clear your browser cache and reload
